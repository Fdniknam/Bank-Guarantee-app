# محاسبه‌گر ضمانتنامه — راهنمای نصب

این پوشه یک **PWA (Progressive Web App)** است: یک برنامهٔ وب که هم روی اندروید و هم روی آیفون مثل یک اپلیکیشن واقعی نصب می‌شود، آیکون مستقل روی صفحه اصلی دارد و بدون اینترنت هم کار می‌کند.

نکته مهم: ساخت یک اپلیکیشن اندروید بومی (فایل APK نصبی) نیازمند محیط ساخت اندروید (Android Studio / Gradle) است که در این محیط در دسترس نیست. راه‌حلی که اینجا ساخته شده، یک **PWA واحد** است که هم در اندروید (Chrome) و هم در آیفون (Safari) قابل نصب است و از نظر تجربه کاربری تفاوت محسوسی با اپ بومی ندارد.

## فایل‌ها
- `index.html` — کل منطق و رابط کاربری برنامه
- `manifest.json` — مشخصات نصب (نام، آیکون، رنگ)
- `service-worker.js` — کش کردن فایل‌ها برای کارکرد آفلاین
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — آیکون برنامه

## نحوه انتشار (لازم برای نصب واقعی)
مرورگرها Service Worker را فقط روی **HTTPS** (یا localhost) اجرا می‌کنند، پس این فایل‌ها باید روی یک هاست قرار بگیرند. ساده‌ترین راه‌ها:

1. **GitHub Pages** (رایگان): این پوشه را در یک ریپازیتوری آپلود کنید و Pages را فعال کنید.
2. **Netlify / Vercel**: کل پوشه را با درگ-اند-دراپ آپلود کنید.
3. هر هاست ساده دیگری که HTTPS دارد.

## نصب روی گوشی
- **اندروید (Chrome):** آدرس سایت را باز کنید → منوی سه‌نقطه → «Add to Home screen» / «نصب برنامه».
- **آیفون (Safari):** آدرس سایت را باز کنید → دکمه Share (مربع با فلش) → «Add to Home Screen».

بعد از نصب، آیکون برنامه روی صفحه اصلی گوشی ظاهر می‌شود و برنامه در حالت تمام‌صفحه (بدون نوار آدرس) باز می‌شود.

## منطق محاسبه (خلاصه)
- سپرده نقدی = درصد سپرده × مبلغ ضمانتنامه (درصد حداقل بر اساس نوع ضمانتنامه انتخابی پیش‌فرض قرار می‌گیرد و قابل افزایش است)
- مبلغ مشمول محاسبه = مبلغ ضمانتنامه − سپرده نقدی
- مبلغ وثیقه = مبلغ مشمول × ضریب نوع وثیقه (سفته و ملکی: ۱۳۰٪ | سپرده بلندمدت: ۱۱۰٪ | سپرده جاری: ۱۰۰٪)
- کارمزد سالانه = مبلغ مشمول × نرخ نوع وثیقه (سفته ۲.۲۵٪ | ملکی ۱.۵٪ | بلندمدت و جاری ۰.۵٪)
- کارمزد ضمانتنامه = کارمزد سالانه × (مدت به ماه ÷ ۱۲)
- کارمزد تشویقی باجه = کارمزد ضمانتنامه × ۳۰٪
- موجودی مورد نیاز برای صدور = کارمزد ضمانتنامه + سپرده نقدی

اگر فرمول تناسب زمانی کارمزد (تقسیم بر ۱۲ ماه) با رویه داخلی بانک شما متفاوت است، در فایل `index.html` تابع `calculate()` را ویرایش کنید.

## دامنه اختصاصی
هم GitHub Pages و هم Netlify امکان اتصال دامنه دلخواه («Custom domain») را در تنظیمات پروژه دارند:
- **GitHub Pages:** Settings → Pages → بخش «Custom domain» → نام دامنه را وارد کنید، سپس نزد ثبت‌کننده دامنه یک رکورد CNAME (برای ساب‌دامنه) یا رکوردهای A (برای دامنه اصلی، به IP های GitHub Pages) اضافه کنید.
- **Netlify:** Site settings → Domain management → «Add custom domain»، سپس رکورد پیشنهادی (CNAME یا A) را نزد ثبت‌کننده دامنه ثبت کنید.

اگر هنوز دامنه نخریده‌اید، توجه کنید برخی ثبت‌کننده‌های بین‌المللی (مثل GoDaddy/Namecheap) به‌دلیل تحریم برای کاربران ایرانی محدودیت دارند؛ دامنه‌های `.ir` را می‌توانید از طریق ثبت‌کننده‌های داخلی (نمایندگان رسمی IRNIC) بگیرید، یا برای `.com`/`.net` از واسطه‌های داخلی معتبر استفاده کنید.
